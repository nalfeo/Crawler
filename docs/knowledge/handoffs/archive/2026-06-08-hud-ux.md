# Session Handoff: HUD UX — health bar, floor timer, minimap

## Date

2026-06-08

## Summary

Added three HUD components to the Phaser engine layer plus a lab and wired them into `MainGameScene`.

### HudHealthBar (`src/engine/HudHealthBar.ts`)

- Bottom-left, fixed to screen (`setScrollFactor(0)`, depth 1000)
- Two `Phaser.GameObjects.Rectangle` objects (shell + fill) — no per-frame Graphics redraw
- Tri-color fill: green (>50% HP), amber (25–50%), red (<25%)
- Phaser tween pulse on fill alpha when HP < 25%
- Reads `world.stores.health.current[playerEid]` / `.max[playerEid]`

### HudFloorTimer (`src/engine/HudFloorTimer.ts`)

- Top-center, fixed to screen
- Shows `Floor N  M:SS` countdown
- Floor 1: reads `world.floor1.objective.deadlineMs - world.elapsedMs`
- Generic fallback: `FLOOR.MAX_DURATION_S * 1000 - world.elapsedMs`
- Amber at <60s, red + pulse tween at <30s

### HudMinimap (`src/engine/HudMinimap.ts`)

- Top-right corner
- **Collapsed** (default): 40×40 icon with "M" hint label, click to expand
- **Expanded**: 200×150 `RenderTexture` terrain bake + `Graphics` dot overlay
- **Discovery model**: local `visitedTiles: Uint8Array` accumulates `floorMap.visible` over time; terrain only rendered for explored tiles (FOV-gated)
- Enemy dots: `query([Enemy, Position])`, only drawn where `floorMap.visible[tileIdx]` is set
- Player dot: always shown in white
- Toggle: M key via `window.addEventListener` (canvas-focus-safe), or click on icon/close button
- Terrain rebaked only when new tiles are explored (not every frame)
- `visitedTiles` resets when `floorMap` reference changes (floor transition)

### HudUI (`src/engine/HudUI.ts`)

- Thin facade owning all three components
- `sync(world, playerEid)` — called from `MainGameScene.updateOverlayText()` every frame
- `destroy()` — called in scene shutdown handler

### MainGameScene changes (`src/engine/scenes/MainGameScene.ts`)

- Removed `statusText` field (objective hint text replaced by HUD)
- `initializeUi()` now creates `HudUI` in addition to `objectiveText` and `loadoutText`
- `updateOverlayText()` calls `hudUi.sync()` first; floor timer removed from `objectiveText`
- Shutdown handler destroys `hudUi` and clears the field

### hud-lab (`src/labs/hud-lab/index.ts`)

- Phaser-based lab (spins up real `Phaser.Game`)
- Synthetic `GameWorld` with a spawned player and fake `floor1` objective
- lil-gui sliders: HP %, max HP, time remaining, floor
- Scene `update()` drives `world.elapsedMs` forward and calls `hudUi.sync()` each frame
- Registered in `src/lab-main.ts` as `hud-lab`

## Notes

- No `visited`/explored array was added to `FloorMap` — the minimap owns its own `visitedTiles` buffer; this avoids touching `src/core/`
- Minimap does not show enemies in unexplored/invisible tiles — preserves FOV intent
- The M-key uses `window.addEventListener` (not Phaser keyboard plugin) to avoid canvas-focus sticking
- Generic floor timer fallback (`FLOOR.MAX_DURATION_S`) has no floor 2+ scenario to validate against — speculative but harmless
