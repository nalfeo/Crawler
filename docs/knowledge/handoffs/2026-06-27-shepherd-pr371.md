review threads, no auto-merge). Drove it to a clean squash-merge.

- **Secrets scan (priority) — FALSE POSITIVE, fixed properly.** Root cause was
  `.github/skills/security-review/references/secret-patterns.md` containing
  AWS's canonical documentation placeholder `AKIA...EXAMPLE`, which the
  scanner's `AKIA[0-9A-Z]{16}` pattern flagged. Sanitized the example literal to

  scanner, exclude a directory, or allowlist anything. No real secret was ever
  committed.

  vendored `chrome-devtools` skill referenced CDP tools

  skill needed a real backing server. MCP server count: 6 → 7.
