# Fix: Docs Update Loop — Prettier failure on INDEX.md

**Session slug**: fix-docs-update-loop-prettier
**Apple estimate**: 🍎
**Date**: 2026-07-27

## Systems touched

ci

## Problem

CI run [30226162515](https://github.com/nalfeo/Crawler/actions/runs/30226162515) failed on the
`docs-update` job at step "Open docs automation PR" with:

```
##[error]Unexpected error: Running Prettier on staged files...
docs/knowledge/handoffs/INDEX.md 244ms
...
```

`peter-evans/create-pull-request@v7` runs Prettier on every staged file before committing them
to the PR branch. `docs/knowledge/handoffs/INDEX.md` is an auto-generated index with handoff
description lines that can reach 246 characters — well over `.prettierrc`'s `printWidth: 100`.
When Prettier reformats the file, the action's internal re-staging step throws an unhandled
exception, aborting the PR creation.

## Fix

Added `docs/knowledge/handoffs/INDEX.md` to `.prettierignore`.

This file is generated by `scripts/agent/docs/build-system-index.ts` and intentionally keeps
full-width description lines for readability. Ignoring it from Prettier means no re-staging
happens, and the `create-pull-request` action commits the file as-is without error.

## Verification

- `npx prettier --list-different docs/knowledge/handoffs/INDEX.md` exits 0 (file ignored)
- `npm run verify:fast` passes: 1719/1719 tests, typecheck clean, lint clean
