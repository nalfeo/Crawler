# Achievements UI Lab

Renders the safe-room **Achievements panel**: each earned achievement shows its
title, unlock condition, Director flavor line, and an "Open reward" button.

- Unlock one or all achievements, then open rewards (reveal-only — no loot granted).
- Validates `claimAchievementReward` / `isAchievementClaimed` (`src/core/systems/achievementRewards.ts`).

Run: `npm run lab` → `?lab=achievements-ui-lab`.
