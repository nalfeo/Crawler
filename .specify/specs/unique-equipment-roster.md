# Spec: Unique Equipment Roster

> **Status:** Normative authored roster for Floor 2 Unique equipment.
> **Authority:** ADR 0066 (schema, acquisition, duplicates).
> **Relationship:** This file is the per-item source of truth. The schema
> contract lives in `.specify/specs/equipment-system.md` § Unique Equipment.

Uniques are singleton authored items. A player either owns a given Unique or
they do not. They are identified by a stable `UniqueEquipmentId` of the form
`unique:<slug>` and are never generated by the procedural instance pipeline.

Each entry below declares the required fields defined in the `UniqueEquipmentDef`
schema and provides a human-readable rationale for the mechanic and duplicate rule.

---

## The Showstopper

```typescript
{
  schemaVersion: 'unique-equipment-def/v1',
  uniqueId: 'unique:showstopper',
  displayName: 'The Showstopper',
  slot: 'mainHand',
  lore: `The weapon the last Floor 2 champion left behind, still warm from the arena lights.
         The crowd remembers every swing. So does the steel.`,
  spriteKey: 'unique/showstopper-weapon',
  iconKey: 'unique-icon/showstopper',
  vfxKey: 'unique-vfx/showstopper-burst',
  acquisitionSource: {
    type: 'boss-drop',
    bossId: 'floor2-arena-champion',
    floor: 2,
  },
  duplicateRule: { type: 'disallow' },
  upgradeLevel: 0,
  maxUpgradeLevel: 0,
  eligibilityPrereqs: [],
  questId: null,
  achievementId: null,
  grants: [],
}
```

### Mechanic — Showtime

While the player is within 10 tiles of an active Director spectator zone (arena
fight, boss room, named set-piece encounter), The Showstopper accumulates
**Showtime stacks** at a rate of 1 per 2 seconds (maximum 10 stacks). Each stack
persists for 8 seconds after leaving a spectator zone.

On attack, all current stacks are consumed and the hit deals bonus damage equal
to `stacks × 4%` of the weapon's base damage. This burst is a single instantaneous
hit applied alongside the normal attack, not a separate projectile.

**Why this cannot be expressed as ordinary effect units:** The `Showtime` mechanic
reads Director state (spectator zone presence) and conditionally modifies attack
damage based on a decaying counter — neither of which maps to any existing affix
type (damage%, speed%, armor, stat). The effect-unit budget model covers additive
stat bonuses; it has no concept of environment-triggered stacking multipliers.

### Acquisition

Boss-drop from the Floor 2 arena champion on first kill. The drop outcome is
computed from the world seed at floor-load (not at kill time) so it is fully
deterministic. If the player already owns this Unique (`disallow` rule), the loot
slot resolves to a Rare generated weapon instead.

### Art Requirements

- **Sprite:** `unique/showstopper-weapon` — a theatrical one-handed bludgeon or
  short sword with a spotlit golden hilt. Distinct from any generated weapon family.
  Larger than standard weapon sprites; includes a subtle camera-flash highlight on
  the blade.
- **Icon:** `unique-icon/showstopper` — the hilt silhouette against a burst of
  spotlight rays. Clearly distinguishable from any generated rarity border.
- **VFX:** `unique-vfx/showstopper-burst` — a brief camera-flash and crowd-roar
  particle effect on stack-consuming attacks (non-looping, ≤ 0.4s).

## Curator's Monocle

```typescript
{
  schemaVersion: 'unique-equipment-def/v1',
  uniqueId: 'unique:curators-monocle',
  displayName: "Curator's Monocle",
  slot: 'face',
  lore: `The Curator built it to find things that didn't want to be found.
         Through it, every item in the dungeon has a price tag and a story.
         The stories are rarely flattering.`,
  spriteKey: 'unique/curators-monocle',
  iconKey: 'unique-icon/curators-monocle',
  vfxKey: null,
  acquisitionSource: {
    type: 'quest-reward',
    questId: 'curator-npc-chain',
  },
  duplicateRule: { type: 'burn', compensation: { type: 'gold', amount: 300 } },
  upgradeLevel: 0,
  maxUpgradeLevel: 0,
  eligibilityPrereqs: [
    { type: 'quest-completed', questId: 'curator-npc-chain-prerequisite' },
  ],
  questId: 'curator-npc-chain',
  achievementId: null,
  grants: [],
}
```

### Mechanic — Appraiser's Sight

While the Curator's Monocle is equipped, item containers (chests, dropped loot,
merchant displays not yet fully revealed) within 12 tiles are highlighted with a
visible aura whose color reflects the highest rarity inside: gray for Common,
green for Uncommon, blue for Rare, and gold for a Unique. The highlight renders
through opaque walls at reduced opacity.

Additionally, hovering any item in the player's inventory or in a nearby container
while the Monocle is equipped reveals one extra tooltip line — the item's base
appraisal value (the gold equivalent the Quartermaster would offer) — even before
the player has visited that merchant.

**Why this cannot be expressed as ordinary effect units:** Appraiser's Sight reads
the world's container state and modifies the rendering layer's item-highlight
decision — a per-frame spatial query and a HUD annotation, neither of which has an
analog in any current stat or ability-type category.

### Acquisition

Quest reward from the Curator NPC chain. The Curator is a unique Floor 2 NPC
found in one of the non-Quartermaster shops. Completing their multi-step fetch
quest (three objectives across the floor) grants the Monocle in a reward bundle
using the same atomic claim model as ADR 0065 DEC-007.

### Art Requirements

- **Sprite:** `unique/curators-monocle` — an ornate brass monocle or lorgnette
  with a tinted lens, clearly worn by the player on their face.
- **Icon:** `unique-icon/curators-monocle` — the circular lens with a faint
  rarity-aura glow around the frame edge.
- **VFX:** none (the highlight aura is a permanent rendering-layer tint, not a
  one-shot effect).

## Floodgate Bracer

```typescript
{
  schemaVersion: 'unique-equipment-def/v1',
  uniqueId: 'unique:floodgate-bracer',
  displayName: 'Floodgate Bracer',
  slot: 'arms',
  lore: `Built by the old armorsmith before the show swallowed his workshop.
         He said the secret was to hold everything in until the moment was right.
         The bracer learned too well.`,
  spriteKey: 'unique/floodgate-bracer',
  iconKey: 'unique-icon/floodgate-bracer',
  vfxKey: 'unique-vfx/floodgate-release',
  acquisitionSource: {
    type: 'boss-drop',
    bossId: 'floor2-main-boss',
    floor: 2,
  },
  duplicateRule: {
    type: 'convert-upgrade',
    upgradeLevel: 1,         // second copy adds 1 upgrade level
    maxUpgradeLevel: 3,      // capped at +3
    atCapRule: 'disallow',   // at upgrade cap, slot resolves to a fallback Rare
  },
  upgradeLevel: 0,
  maxUpgradeLevel: 3,
  eligibilityPrereqs: [],
  questId: null,
  achievementId: null,
  grants: [],
}
```

### Mechanic — Stored Kinetics

The Floodgate Bracer captures a percentage of damage absorbed by the player and
stores it as a single **Charge**. The Charge accumulates up to `20% of the
player's max HP` worth of absorbed damage. On the player's next attack after the
Charge reaches any nonzero level, the entire stored Charge is released as a bonus
burst hit (not consuming the normal attack's damage). The Charge then resets to
zero.

At `upgradeLevel` 0 the capture rate is 25% of absorbed damage. Each upgrade level
adds 5% capture rate (cap: 40% at `upgradeLevel` 3). The burst release is always
100% of the stored amount regardless of upgrade level.

**Why this cannot be expressed as ordinary effect units:** The mechanic requires
tracking a per-entity float counter that fills from incoming damage events and
drains on attack, multiplied by a capture rate. No existing stat affix type covers
damage-absorption tracking or attack-triggered release of a stored non-stat value.

### Acquisition

Boss-drop from the Floor 2 main boss on first kill, seed-deterministic at
floor-load. On a second encounter (NG+ or a different seed), if the player already
owns a `upgradeLevel < 3` copy, the `convert-upgrade` rule increments the owned
copy's upgrade level by one and no new copy is created. If the player already owns
a `upgradeLevel == 3` copy, the slot resolves to a Rare generated piece of armor
instead.

### Art Requirements

- **Sprite:** `unique/floodgate-bracer` — a heavy industrial bracer with a
  hydraulic pressure gauge and a release valve. Glows faintly when Charge is
  building; valve pulses on release.
- **Icon:** `unique-icon/floodgate-bracer` — the pressure gauge at full.
- **VFX:** `unique-vfx/floodgate-release` — a radial water/hydraulic pressure
  burst emanating from the player on the release attack. Non-looping, ≤ 0.5s.

## Contestant's Ring

```typescript
{
  schemaVersion: 'unique-equipment-def/v1',
  uniqueId: 'unique:contestants-ring',
  displayName: "Contestant's Ring",
  slot: 'ringLeft',
  lore: `Property of the show. Non-transferable. The rules say the winner keeps it.
         Nobody has ever asked what happens when the winner dies.`,
  spriteKey: 'unique/contestants-ring',
  iconKey: 'unique-icon/contestants-ring',
  vfxKey: 'unique-vfx/contestants-revival',
  acquisitionSource: {
    type: 'achievement-reward',
    achievementId: 'survive-floor2-deathless',
  },
  duplicateRule: { type: 'disallow' },
  upgradeLevel: 0,
  maxUpgradeLevel: 0,
  eligibilityPrereqs: [
    { type: 'achievement-completed', achievementId: 'survive-floor2-deathless' },
  ],
  questId: null,
  achievementId: 'survive-floor2-deathless',
  grants: [],
}
```

### Mechanic — Last Contestant Standing

While the Contestant's Ring is equipped, the player has one revival charge per
floor. If the player would die while the charge is available, the death is
prevented, the charge is consumed, and the player is restored to 30% of their
maximum HP in place. A brief invulnerability window (1 second) prevents the
restored player from dying immediately to residual damage.

The charge resets at floor transition. It does not reset between encounters within
a floor. A UI indicator on the ring's equipment slot shows charge state.

**Why this cannot be expressed as ordinary effect units:** Revival prevention and
HP restoration on a per-floor consumable charge require a death-hook interception
and a mutable charge-state field. No existing stat or ability type in the current
budget catalog has a death-prevention or HP-restore-on-death semantic.

### Acquisition

Achievement reward for completing Floor 2 without dying in a single floor run.
Granted at achievement-unlock time using the ADR 0065 DEC-007 atomic claim model.
Because the `disallow` rule applies, and the eligibility prerequisite is the
achievement itself, it is impossible to receive a duplicate through normal play.

### Art Requirements

- **Sprite:** `unique/contestants-ring` — a thick signet ring bearing the show's
  emblem (stylized dungeon entrance or camera lens). A faint heartbeat pulse effect
  when the revival charge is active; visual dimming when spent.
- **Icon:** `unique-icon/contestants-ring` — the signet face with a heartbeat
  flatline stylized on it.
- **VFX:** `unique-vfx/contestants-revival` — a short burst of bright light and
  confetti-like particles at revival (crowd-reaction aesthetic). Non-looping, ≤ 1s.

## Regret's Echo

```typescript
{
  schemaVersion: 'unique-equipment-def/v1',
  uniqueId: 'unique:regrets-echo',
  displayName: "Regret's Echo",
  slot: 'neck',
  lore: `The dead whisper to it. It remembers every hit, every dodge, every mistake.
         Wear it long enough and you'll start to wonder if the memories are yours.`,
  spriteKey: 'unique/regrets-echo',
  iconKey: 'unique-icon/regrets-echo',
  vfxKey: 'unique-vfx/regrets-chain-burst',
  acquisitionSource: {
    type: 'quest-reward',
    questId: 'echo-keeper-hidden-chain',
  },
  duplicateRule: {
    type: 'burn',
    compensation: { type: 'crafting-fragment', fragmentId: 'echoed-shard', count: 1 },
  },
  upgradeLevel: 0,
  maxUpgradeLevel: 0,
  eligibilityPrereqs: [
    { type: 'npc-dialogue-state', npcId: 'echo-keeper', stateKey: 'unlocked' },
  ],
  questId: 'echo-keeper-hidden-chain',
  achievementId: null,
  grants: [],
}
```

### Mechanic — Echoed Finish

Regret's Echo tracks the last three combat hits the player dealt (damage value,
target entity ID, and relative position) in a rolling buffer. On kill, there is a
5% chance the Echo triggers: each of the three buffered hits is replayed
sequentially as chain strikes against the nearest living enemy within 8 tiles,
using the original damage values and ignoring the player's current attack speed.
The chain burst does not grant additional XP or item drops.

**Non-proccing contract:** Echoed chain strikes are explicitly non-proccing.
They are excluded from the rolling hit buffer (echoed hits cannot replace the
buffer with their own values or extend the chain). They cannot trigger Echoed
Finish themselves (no recursive chains). They do not fire any on-hit or on-kill
side-effects (including ability procs, status applications, or further grant
triggers). The kill that initially triggers the Echo is the only kill counted
for on-kill purposes during a chain burst.

At `upgradeLevel` 0 the trigger probability is 5%. The upgrade level for this
Unique is fixed at 0 (the `burn` duplicate rule prevents any upgrade path).

**Why this cannot be expressed as ordinary effect units:** The mechanic requires a
rolling event buffer (last-three-hits), an on-kill probability trigger, and a
replayed multi-hit burst dispatched to an arbitrary target — a sequence that spans
combat events, entity state, and ability dispatch in a way that no existing stat
affix type or ability type can express.

### Acquisition

Hidden quest reward. Regret's Echo is obtained by completing the multi-step Echo
Keeper NPC chain, which is only discoverable through a specific NPC dialogue branch
on Floor 2 (the Echo Keeper, a minor NPC who appears in certain room types). The
chain requires three steps spread across different room types before the NPC
offers the Unique as a final reward. The item is listed in the achievement/quest
log only after the chain is discovered; it does not appear in the Quartermaster's
catalogue.

A second copy burns to an **Echoed Shard** crafting fragment (a currency used in
future planned upgrade systems); if the player already owns the item and encounters
the quest resolution again, the director narrates a brief flavour comment before
the burn.

### Art Requirements

- **Sprite:** `unique/regrets-echo` — a dark amulet or pendant housing a small
  cracked crystal that contains swirling smoke. The smoke animates subtly at idle.
- **Icon:** `unique-icon/regrets-echo` — the cracked crystal face with wisps.
- **VFX:** `unique-vfx/regrets-chain-burst` — rapid ghostly re-trace lines of the
  three echoed hits connecting the player to the target (afterimage style).
  Non-looping, ≤ 0.6s.

## Art Production Plan

Each Unique requires a dedicated production wave outside the `floor2-equipment`
generated-art pipeline. The five Uniques above constitute the **Unique Wave 1**
brief set. Production order (suggested by acquisition rarity and player impact):

1. Contestant's Ring — achievement-gated; lower urgency but high visibility
2. Curator's Monocle — quest-reward; needed alongside Curator NPC art
3. The Showstopper — boss-drop; tied to arena-champion boss implementation
4. Floodgate Bracer — boss-drop (main boss); tied to main boss implementation
5. Regret's Echo — hidden quest; latest dependency

Each item needs: one 32×32 equipped sprite (`unique/<slug>`), one 20×20 icon
(`unique-icon/<slug>`), and optionally a short non-looping VFX particle set
(`unique-vfx/<slug>`). Art is human-authored outside the procedural generation
pipeline and ingested via `sprites:checkin` after creation and approval. The
generation pipeline (`sprites:run`, `sprites:enqueue`) must not be used for
Unique art slots.
